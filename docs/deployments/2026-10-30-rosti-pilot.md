# Private pilot deployment record

The installation-specific record is maintained outside this repository in the
operator's protected records. It includes provider resource identities, SSH
connection details, deployment observations and backup inventory. Do not copy
those records, environment files or backup archives into Git or CI artifacts.

Use [deployment and recovery](../deployment.md) for the versioned, reusable
operating procedure. Obtain installation-specific values from the authorized
operator's private records and protected secret store.
