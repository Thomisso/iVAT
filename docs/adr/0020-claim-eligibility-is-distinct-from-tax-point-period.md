# Claim eligibility is distinct from the Tax Point Date's period

A Tax Point Date still proposes a Document's default Reporting Period, but ordinary incoming domestic claims also record an Earliest Claim Period and must satisfy the applicable filing deadline. This replaces ADR-0012's general three-year limit and its earlier trade-off accepting the Tax Point Date's period without checking possession: predictable proposals must not silently become claims for an ineligible period. Use a confirmed period rather than inventing an exact Receipt Date from upload metadata.

For an ordinary incoming Document whose Tax Point Date, issue date and actual Source File Import Date all fall in the same generated Reporting Period, the system may infer that Earliest Claim Period independently of whether the Company's automatic approval is enabled. This rule does not itself approve the Document. A Document without a Source File cannot qualify through an invented Import Date. Otherwise a User confirms the Earliest Claim Period; AI or a later upload cannot infer earlier possession. Preserve the value and its provenance with the saved Document state, without rewriting immutable Extraction Versions or historical reports. Import Date is not a replacement for actual receipt, and the same-period policy does not assert that all substantive tax conditions have been independently proven.

The User explicitly confirmed this independence on 13 November 2026 in [#335](https://github.com/Thomisso/iVAT/issues/335). That clarification preserves the shipped same-period behavior; its documentation is reconciled through [#324](https://github.com/Thomisso/iVAT/issues/324), without changing approval policy or introducing a new tax interpretation.

Deadline rules distinguish entitlements arising before 1 January 2025 from those arising from that date. Preparation and new export evaluate the applicable deadline as of the current date and display the last filing date; finalization and export do not constitute filing. Historical reports remain preserved and downloadable. The exact holiday/weekend boundary of the old three-year rule must be verified before implementing that calendar block, as recorded in the specification.

In this version Deferred Claim is available only for supported ordinary incoming domestic supplies. Reverse charge and EU self-assessment retain one common period without a shared deferral: moving both output liability and input deduction would misstate the former. Separate periods are deferred to [#221](https://github.com/Thomisso/iVAT/issues/221); legacy deferred cases require manual resolution before new report preparation, without rewriting locked reports.

Accepted during the design session on 6 November 2026; implementation is pending. The complete supported scope and acceptance cases are in [the shared specification](../document-review.md).
