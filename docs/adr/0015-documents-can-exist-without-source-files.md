# Documents can exist without Source Files

A Document may be entered manually without a Source File, rather than requiring an uploaded or fabricated file. This makes manual entry and recovery from failed AI Extraction first-class paths while keeping Source File as the unchanged original evidence when a file actually exists.

Manual entry creates User-authored immutable Extraction Versions under ADR-0005 and follows the same validation, human approval, authorization and Period Locks as AI-extracted data. Every manual save requires a valid Tax Point Date; selecting a Reporting Period is not a substitute. Other missing required data may remain in a draft but prevents approval. Reporting Period assignment continues to follow ADR-0012, without a new provisional period or invented date. A first manual draft may be preserved for review when its Tax Point Date points into a locked period; this does not assign or approve it into that period. Manual work does not consume AI Processing Allowance.

A Source File may be attached later outside a Period Lock without changing the Document's identity or approval or automatically invoking AI. After an explicit warning and confirmation, a User may request AI Extraction, withdrawing any existing approval. Successful Extraction replaces the current structured values with a new AI-authored Extraction Version requiring human review; historical User-authored versions remain unchanged. Failure preserves the last manual data without automatically restoring approval. Successful AI Extraction consumes AI Processing Allowance under the existing rules.
