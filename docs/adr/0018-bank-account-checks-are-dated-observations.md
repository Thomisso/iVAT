# Bank Account Checks are dated observations

Bank-account publication can be checked again without correcting a Document's extracted data. Store each new Bank Account Check as a dated observation separate from immutable Extraction Versions and retain historical results, rather than rewriting prior findings or requiring a new Document revision solely to refresh the register result.

An explicit manual check is available to Users who already have access to the Document, including Approved Documents in a locked Reporting Period. It does not change Document data, approval, the Period Lock or VAT Reports; a fresh result describes current registry publication and cannot prove historical publication when the Document was issued. This preserves ADR-0005 and ADR-0007 while allowing existing false bank-account warnings to be superseded without reopening accounting work. Automatic bulk refresh is outside this change.
