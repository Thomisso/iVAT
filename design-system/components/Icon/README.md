# Icon

Sixteen 16px stroke icons drawn for iVAT; pass `name`, optionally `size` and `label`.

- 1.5px stroke, round caps and joins, `currentColor`. Set colour with CSS `color` from a token (`ink-muted` for idle, `accent`, `ai`, a status colour).
- `marker` is the AI's glyph (a highlighter). Use it only where the AI proposed something; never as decoration.
- Pass `label` when the icon carries meaning on its own (no visible text beside it); otherwise it is hidden from assistive tech.
- Names: `check alert info error marker upload file search lock chevron duplicate inbox send report building split arrow clock`.
- Need one that isn't here? Take it from Lucide at 16px with stroke 1.5 so it matches.
