# DropZone

Where Source Files enter a Company; pass `title`, `hint`, `accept`, `over` and `onFiles`.

- The whole zone is the target; dragging over it turns it `accent-soft` (`over`).
- The hint names the accepted formats and the promise the product keeps: "PDF, PNG or JPEG. The original is kept unchanged."
- After a drop each file appears as a row with status `uploaded`, then `splitting` and `extracting`; the zone stays put for the next batch.
