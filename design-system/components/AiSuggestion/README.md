# AiSuggestion

A decision the AI proposes and a human confirms, with the reasons; pass `title`, `reasons`, `confidence`, `eyebrow`, `onAccept`, `onChange` and optional children.

- Use it for judgements, not for values: the VAT Regime, the Direction, a Split of a multi-document Source File, a likely duplicate.
- The title states the proposal as a fact the user can accept: "Domestic reverse charge (§ 92a)".
- Give two to four reasons that point at the document: what the AI saw and where. No hedging words; the confidence pips carry the uncertainty.
- Accepting never files anything. It sets the value; the Document still needs approval.
