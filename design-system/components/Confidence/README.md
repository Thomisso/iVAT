# Confidence

How sure the AI is about one value, as three pips and a word; pass `value` (0 to 1) and `compact` to hide the text.

- High ≥ 95 %, Medium ≥ 80 %, Low below. Low turns `warning` and the value must be checked before approval.
- Show it next to AI-proposed values only. Once a human approves or edits a value, the confidence goes away: it no longer describes anything.
- Never show bare percentages without the word; "93 %" alone invites false precision.
